# Design vs backend: what the frontend does

The Figma design was finished after the backend was built, so a few things differ. **The frontend follows the live backend today** and uses the fallbacks below. Items marked **Ask Afan** are small backend changes that unlock the full design; when one ships, switch from the fallback to the designed behavior.

| # | Topic | Design says | Backend does | Frontend does now | Ask Afan? |

| 1 | Currency | User picks currency (IDR, MYR, SGD, USD, JPY, INR); demo shown in USD | Profile and all math in **IDR** | Show rupiah everywhere. Currency field on 01a shows "🇮🇩 IDR · Indonesian Rupiah", not tappable. Hide sheet 01a·s. | No (roadmap) |
| 2 | Work pattern | Hours/day × days/week + presets | `hoursPerWeek` (1–120) | Send `hoursPerWeek = hoursPerDay × daysPerWeek`. Settings shows it back as "8h × 5 days" when it divides cleanly, else "40 h/week". | No |

Keep the Avoid-interest question; store the answer in `localStorage` (`tt.avoidInterest`) and use it only to show "Contains interest" chips.
